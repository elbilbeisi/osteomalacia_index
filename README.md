# Osteomalacia / Osteoporosis Discriminant Index

Web calculator for the McKenna diagnostic index distinguishing osteomalacia from osteoporosis.

**Live tool:** https://elbilbeisi.github.io/osteomalacia_index/

## Method

Index % = points scored / points possible for the parameters available (limb pain, proximal myopathy, Ca x P product, alkaline phosphatase, 25(OH)D, pseudofractures). Interpretation: >35% osteomalacia; 15-35% bone biopsy indicated; <15% osteomalacia unlikely.

## Caveats

Derived in 41 retrospective patients with normal renal function and never prospectively validated. Thresholds reflect 1980s assays. Not applicable in CKD-MBD. Decision support only; does not replace clinical judgement or histomorphometry.

## Reference

McKenna MJ, Freaney R, Casey OM, Towers RP, Muldowney FP. Osteomalacia and osteoporosis: evaluation of a diagnostic index. J Clin Pathol 1983;36:245-252. doi:10.1136/jcp.36.3.245
